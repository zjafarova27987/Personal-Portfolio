# Zohra's Digital Universe

A Stage 1 portfolio project for SITE 1101: Personal Portfolio Website.

## Project focus

This project is the initial foundation for a dreamy, magical portfolio website inspired by floating islands, soft skies, and interactive exploration. The site is intentionally simple and modular so it can grow into a more complete portfolio later.

Important note: this project does not invent personal biography, achievements, skills, qualifications, or project contributions. Placeholder text is used until authentic content is provided.

## Current development status

- Homepage structure created
- Modular CSS and JavaScript foundation established
- Responsive layout and reusable CSS variables added
- Explore My World button connected to smooth page navigation
- Interactive fantasy world map prototype with five floating destination islands added
- Keyboard-friendly island navigation and hover information panel included

## How to run locally

1. Open a terminal in this project folder.
2. Start a local web server:

```bash
python3 -m http.server 8000
```

3. Open the site in a browser:

```text
http://localhost:8000
```

## Important learning notes

- HTML provides the structure of the page.
- CSS controls the visual design, spacing, colors, and responsiveness.
- JavaScript adds interaction without creating a full feature-heavy game yet.
- Keeping files in separate folders makes the project easier to manage as it grows.
